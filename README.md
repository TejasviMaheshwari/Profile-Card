# Profile Card UI/UX Design

## 📌 Project Overview

This project is a simple and attractive **Profile Card UI/UX Design** created using HTML and CSS. It displays a software developer's profile with college details, social media icons, interactive-style buttons, and engagement statistics in a clean navy-blue layout.

## ✨ Features

* **Profile Card:** Circular profile image with a styled header.
* **Personal Details:** Displays the software developer role, college name, and BCA year.
* **Social Media Icons:** Facebook, Instagram, GitHub, LinkedIn, and Behance.
* **Action Buttons:** Subscribe and Message buttons.
* **Engagement Statistics:** Displays likes, comments, and shares.
* **Modern Design:** Navy-blue theme, rounded corners, and a card-style layout.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome Icons

## 🚀 How to Run

1. Download or clone this repository.
2. Make sure `index.html` and `Mountain.png` are in the same folder.
3. Open `index.html` in your web browser.
4. Explore the profile card design.
